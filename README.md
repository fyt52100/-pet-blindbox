# 驻屏生物 SCREENLINGS · 桌面宠物盲盒

一个用 AI 参与生成素材、以盲盒抽取为入口的桌面宠物小作品。抽中一只，它就从盒子里跳到你眼前，赖着不走。

- 网页版：纯静态单页，无需安装，浏览器打开就能玩
- 桌面版：Electron 透明置顶窗口，宠物真的住在 Windows 桌面上（见下文说明）

## 在线体验

部署到 GitHub Pages 后的地址：

```
https://<你的GitHub用户名>.github.io/<仓库名>/
```

## 目录结构

```
index.html          盲盒页入口（静态单页）
gacha.css           页面样式：奶油底、双光晕、卡池网格
gacha.js            抽奖逻辑、宠物状态机、精灵图逐帧播放
sprites/            6 角色 × 4 动作的 PNG 精灵图（横向逐帧）
  meta.js / meta.json   帧数与每帧时长
assets/characters/  卡池缩略图（每只角色的定妆图，已压到 420px 高）
.nojekyll           关闭 Jekyll，保证静态文件原样发布
```

## 本地运行

方式一：直接双击 `index.html`（`file://` 打开，自动进入网页模式）。

方式二（推荐，避免个别浏览器的本地文件限制）：

```bash
python -m http.server 8000
# 然后浏览器访问 http://127.0.0.1:8000/
```

## 怎么玩

| 操作 | 反应 |
| --- | --- |
| 点「抽盲盒」或点卡池里任意一只 | 抽一次，宠物直接落在页面右下角 |
| 鼠标在页面上移动 | 它朝鼠标方向走过去 |
| 敲键盘 | 它捂上眼睛，停手一秒再松开 |
| 鼠标静止约 8 秒 | 趴下睡着，一动就醒 |
| 单击它 | 大笑一下 |
| 按住拖动 | 拎到页面任意位置，位置被记住 |
| 再抽一次 | 新的顶掉旧的，页面里始终只陪一只 |

卡池：五只普通款各 18%（水豚噜噜、呆呆鸟、三花、科曼尼奇、小黄），隐藏款「奶蛙」10%。

## 桌面版（Electron）

网页版里宠物只在页面内活动；要让它在 Windows 桌面上到处走、盖在其他软件之上、敲键盘就捂眼，需要运行桌面版程序 `Desktop Pet.exe`（随压缩包分发，约 178 MB，自带运行时，无需装 Node/Electron）。

桌面版与网页版共用同一套素材与动画数据，区别只在承载窗口：桌面版是透明、置顶、无边框的独立窗口。

## 制作说明

角色形象与关键动作帧由 AI 图像生成模型产出，再经程序化后处理进入项目：

1. 六只角色的定妆图：以用户手绘/参考图为锚点，用图生图统一风格，得到透明底定妆图；
2. 动作帧：走路、大笑、睡觉、蒙眼四类，按“单帧生成 + 几何对齐 + 统一调色”的流程合成 GIF/精灵图，避免逐帧重绘导致的体形漂移与色调跳变；
3. 精灵图：GIF 拆帧后横向拼接为 PNG，由 `gacha.js` 按每帧时长用 `requestAnimationFrame` 推进 `background-position`，规避部分浏览器对 GIF 的渲染差异；
4. 页面与逻辑：AI 辅助编写，人工逐轮验收，关键参数（宠物尺寸 57×70 px ≈ 1.5 cm、帧时长、抽奖权重）由人工确定。

完整的提示词与迭代过程见《AI 交互记录》。

## 已知限制

- 网页模式的键盘交互需要物理键盘，手机上没有；
- 桌面版仅支持 Windows；
- 精灵图分辨率按 320×350 画布设计，极大屏放大后会略糊。
