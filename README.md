# 桌面宠物盲盒 · Desktop Pet Blind Box

《人工智能基础与应用》课程作品。网页端抽取盲盒角色，抽中的宠物会以透明窗口的形式驻留在 Windows 桌面。

- 演示地址（GitHub Pages）：https://<你的用户名>.github.io/<仓库名>/
- 六个角色：水豚噜噜 / 呆呆鸟 / 三花 / 科曼尼奇 / 小黄 / 奶蛙
- 每个角色四套动作：走路 walk、大笑 laugh、睡觉 sleep、蒙眼 cover

## 一、网页端怎么玩

1. 打开页面，点击「抽一个」按钮开始抽盒，抽到的角色卡片会翻开展示。
2. 点卡片可切换动作，或直接点画面里的宠物切换。
3. 抽过之后页面进入「网页模式」：宠物会自己走动、随机切换动作，左下角出现「送到我的桌面」按钮。
4. 点「送到我的桌面」，这只就从网页上退场，直接住进 Windows 桌面，不再在页面里重复出现；按钮同时变成「点这里请回来」，想再在网页上看它就再点一次。
5. 左上角「重新抽」可以重新摇一次。

键盘交互：`1` 走路、`2` 大笑、`3` 睡觉、`4` 蒙眼、`Esc` 取消，点名的动作保持 5 秒后交还给自动状态；按其他任意键则是「临时蒙眼」，松手约 1 秒后松开。

> 键盘要在页面被点过、页面有焦点时才响应——这是浏览器的安全机制，不是程序失灵。桌面版是 64×70 的透明小窗，系统只把键盘送给它获得焦点的窗口，所以桌面上的小家伙收不到你正在别处敲的字。

## 二、本地运行（不联网也能跑）

本仓库是纯静态站点，没有任何构建步骤，也不需要 npm。

方式一：直接双击 `index.html`。浏览器会以 `file://` 打开，程序自动进入网页模式，功能全部可用。

方式二：起一个本地静态服务（推荐，更接近线上环境）：

```bash
python -m http.server 8080
```

然后访问 http://127.0.0.1:8080/ 。

## 三、部署到 GitHub Pages

1. 把本目录所有文件上传到仓库**根目录**（仓库首页必须能直接看到 `index.html`，不能多套一层文件夹）。
2. 打开仓库 Settings → Pages，Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，保存。
3. 等 1～2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。
4. 更新文件后浏览器请按 `Ctrl + Shift + R` 强制刷新，避免读到旧缓存。

判断新版是否生效：宠物边缘没有白圈，且页面左下有「送到我的桌面」按钮。

## 四、「送到我的桌面」是怎么实现的

浏览器出于安全策略，禁止 https 页面直接访问本机 `http://127.0.0.1`（混合内容拦截），所以网页无法直接把宠物推进桌面程序。本作品改用 **自定义 URL 协议** 作为桥梁：

- 桌面版安装/运行后，会在系统注册 `petbox://` 协议。
- 网页里点击「送到我的桌面」，浏览器会调用 `petbox://pet/<角色id>`，由操作系统把它交给桌面版程序。
- 桌面版解析参数、校验角色白名单后，把该角色写进自己的配置文件并热重载，桌面宠物立刻换成新角色。
- 若本机未安装桌面版，浏览器调用协议会失败，页面会提示「电脑上还没装桌面版」。

桌面版为免安装 exe，见课程提交材料中的「桌面宠物盲盒」压缩包，解压后双击 `Desktop Pet.exe` 即可。

## 五、目录结构

```
.
├─ index.html            入口（盲盒主页面）
├─ gacha.css             页面样式与宠物渲染样式
├─ gacha.js              抽盒逻辑、精灵图动画、协议跳转
├─ sprites/              24 张精灵图（6 角色 × 4 动作）+ meta.js / meta.json
├─ assets/characters/    6 张角色定妆图（卡片展示用）
├─ .nojekyll             关闭 GitHub Pages 的 Jekyll 处理
└─ README.md
```

## 六、实现要点

- 精灵图动画：每个动作是一张横向排列多帧的大图，通过 `background-position` 逐帧推移，配合 `requestAnimationFrame` 控制帧速，避免 `setInterval` 抖动。
- 切换动作不卡顿：页面初始化时预取四个动作的整图并缓存，切换时不再临时解码；且只在动作真正变化时才改写 `background-image`。
- 去除白边：精灵图做了「颜色扩散 + alpha 羽化」处理，让轮廓外的透明像素继承角色本体颜色，缩小时不再混入白色；同时去掉原先的白色柔光层，改用投影表现浮起感。
